# RLCD 多源音乐网关实现计划

## 目标

复用 `go-music-api` 的多平台搜索、代理播放、歌词和智能换源能力，让 RLCD 板型能够搜索并播放网易云音乐，同时在免登录内容不可用时尝试其他公开音源。

## 边界

- 平台协议、Cookie、签名和防盗链处理全部留在外部网关。
- ESP32 只保存网关基础 URL，不保存平台账号和 Cookie。
- 设备不绕过版权、地区、会员或登录限制。
- 网关客户端属于 RLCD 板型，不把板型专用配置放进核心模块。

## 实现

1. 用纯 C++ 模型负责 URL 校验、编码和端点构造，并加入主机测试。
2. 新增板型网关客户端，解析搜索结果、限制响应大小和缓存最近 12 条结果。
3. 播放前调用 `inspect`；不可用或探测失败时调用 `switch` 自动换源。
4. 音频使用网关 `stream` 代理，歌词使用纯文本 LRC 接口，复用已有播放和歌词页面。
5. 增加配置、状态、搜索和按序号播放的 MCP 工具。
6. 提供引用上游镜像的 Docker Compose 和部署说明。

## 验证

- 主机单元测试覆盖 URL 校验、UTF-8 编码以及各播放端点。
- 运行全部脚本测试。
- 使用 ESP-IDF 6.0.2 构建 `waveshare/esp32-s3-rlcd-4.2`。
- 真机仍需验证局域网访问、实际平台可用性、长时间音频流、歌词同步和自动换源。
